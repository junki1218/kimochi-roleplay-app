## 1. 何に使う画像か

特別支援学校（知的）中学部の授業アプリ。iPad（横画面）に絵を大きく出し、
「この こは どんな きもち？」と問いかけて、生徒が気持ちカードで答える。

- **場面イラスト**: 人物の表情・体の動き・状況から、気持ちを推測するための絵
- **気持ちカード**: 回答用。粘土の玉に顔をつけた「顔マーク」。生徒が自分の iPad でタップして、まわりに見せる

**正解を1つに決める絵ではない。** 表情・体・状況の手がかりがはっきり描かれていれば十分。
「どこを見てそう思った？」と話し合えることが大事。

## 2. 共通スタイル：既存素材に合わせる（最重要）

流用する既存画像（Google ドライブ `画像材料/ClayAnimation/`）と並べて違和感がないこと。
詳しい定義はワークスペースの `claymation_style_guide.md` と同じ。要点は次のとおり。

| 項目 | 指定 |
|---|---|
| タッチ | **3D クレイアニメ調**。粘土人形をストップモーションで撮ったような質感。柔らかい影 |
| 人物 | **中学生**。2頭身のちびキャラ。紺のブレザー（ネクタイ・リボンなし）、男子はグレーのスラックス、女子はネイビーかチェックのスカート |
| 表情 | 大きな丸い目。眉・目・口で気持ちをはっきり描き分ける。体の動き（手・肩・姿勢）でも示す |
| 主役 | 気持ちを問われる人物を**1人**決め、**手前・中央・いちばん大きく**描く。ほかの人物は奥か脇に小さく |
| 背景 | 教室・廊下・校庭などの日常風景。細かく描きすぎず、主役が引き立つように整理する |
| サイズ | **1024×1024 px の PNG**（既存素材と同じ正方形） |

### 既存素材と変えるところ（新規分だけのルール）

既存素材には黒板・掲示物の英字やセリフの吹き出しが入っているが、新しく作る分には入れない。

- **文字・数字・ロゴ・吹き出しを一切入れない**（黒板・掲示物・服の胸の文字も無地にする）
- **「？」マーク・電球・怒りマーク（💢）などの漫画記号を使わない**。
  気持ちは顔と体だけで表す。記号があると、生徒が顔を見ずに記号だけで答えてしまうため。
  涙・ほおの赤み・汗は表情の一部として使ってよい
- 怖い表現（血・大けが・暗闇）は避ける

### プロンプトの型（場面）

```
A cute 3D claymation style scene showing {状況}. {主役の人物と表情・動作}.
{ほかの人物}. Japanese junior high school, chibi two-heads-tall proportion,
dark navy blazer without tie. The main character is in the front center and largest.
Beautiful clay model texture, soft shadows, vibrant and bright colors, simple background.
No text, no letters, no numbers, no speech bubbles, no question marks, no comic symbols.
```

### プロンプトの型（気持ちカード）

既存の `clay_emoji_*.png`（赤い怒り顔・黄色い笑顔・青い泣き顔など）と同じ作り。

```
A single round clay ball with a {表情} face, 3D claymation style, {色} clay,
centered and large, on a plain {同系色の淡い色} clay-textured background,
soft studio lighting, soft shadows, no text, no letters, no symbols.
```

ネガティブ（指定できる場合）:
`text, letters, numbers, speech bubble, question mark, light bulb, anger symbol, watermark, realistic photo, scary, dark`

## 5. 納品の約束（全タスク共通）

1. 置き場所: `.agent_flow/assets/` 直下（サブフォルダを作らない）
2. `.agent_flow/ASSET_MANIFEST.json` の `assets` に1枚1件で追記:

```json
{
  "id": "ba_11",
  "type": "image",
  "purpose": "場面イラスト: アイスを落とした（かなしい）",
  "file_path": ".agent_flow/assets/asset_TASK-001_ba_11_aisu.png",
  "dimensions": "1024x1024",
  "created_by": "Antigravity",
  "task_id": "TASK-001",
  "prompt": "（実際に使ったプロンプト）"
}
```

3. **一覧シート**を1枚作る: 生成した全画像をサムネイルで並べ、下に id と気持ちを入れた確認用画像。
   **流用する既存素材（3章）も同じシートに並べ**、画風がそろっているかを一目で見られるようにする
   → `.agent_flow/artifacts/verify_TASK-00N.png`（確認用なので文字を入れてよい）
4. `done_TASK-00N.json` と `logs/log_TASK-00N_agy.md` を書く。ログには、
   作り直した画像と、気持ちが伝わりにくいと感じた画像（自己申告）を必ず書く
5. **Google ドライブへのコピー**: 生成したアセットと一覧シートを
   `G:\マイドライブ\04_素材ライブラリ\画像材料\kimochi-roleplay-app\`（assets / artifacts）にもコピーする。
   **既存の `ClayAnimation` `animal school` フォルダには書き込まない**

## 6. 受け入れ時にクロコが見るところ

- [ ] 既存のクレイ素材と並べて画風がそろっている（質感・頭身・制服・色の明るさ）
- [ ] 絵の中に文字・数字・吹き出し・漫画記号がない
- [ ] 主役が手前・中央・いちばん大きい
- [ ] 気持ちの手がかりが、顔と体の両方に描かれている
- [ ] 怖い表現がない。割り込む子・取る子が悪人顔になっていない
- [ ] 気持ちカードが既存の5色とかぶらない
- [ ] 枚数・ファイル名・台帳登録が一致（`agent_flow.py verify` で機械検査）
