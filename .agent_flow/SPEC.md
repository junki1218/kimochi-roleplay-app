# SPEC：おなじ ことば・ちがう きもち（仮称）

- 発行: クロコ 2026-10-07
- 元の要件定義: Notion「人との関わり・コミュニケーション授業アプリ 要件定義（初版）」（メモ基地 / 📥 メモDB）
- この SPEC は、要件定義に 2026-10-07 の相談で決まったことを上書きしたもの。食い違ったらこちらが正

## 1. 目的

特別支援学校（知的）中学部「人との関わり・コミュニケーション」グループの授業で使う。
同じ言葉でも、気持ちや声・表情・態度で意味が変わることを、ロールプレイで体験的に学ぶ。

- 正しい気持ちを当てることを目標にしない。「自分はどう感じたか」「何を手がかりにそう思ったか」を大事にする
- **場面モードでは正解を表示しない。** その場の話し合いで決める
- **じぶんで やるでは、出題者が選んだ気持ちを「こたえ」として発表できる**（答え合わせ画面）
- AI による感情判定は入れない

## 2. 使う環境

| 項目 | 決定 |
|---|---|
| 端末 | 子どもの iPad。**横画面** |
| 台数 | 出題者 1台 ＋ 回答者の生徒全員が1台ずつ |
| 端末間の通信 | **しない**。各端末がそれぞれ独立して動く |
| モニター | 出題者の iPad だけをミラーで映す |
| 回答の見せ方 | 回答者は自分の iPad をまわりに見せる |
| 置き場所 | GitHub Pages（PWA。ホーム画面に追加して使う） |

## 3. 画面の流れ

```
スタート ─┬─ はじめる ─┬─ もんだいを だす ─┬─ ばめんを えらぶ
          │            │                    │    場面一覧 → 場面表示（絵＋セリフの吹き出し＋「どんな きもちで いったかな？」）→ つぎへ／もどる
          │            │                    └─ じぶんで やる
          │            │                         セリフを選ぶ → 気持ちを選ぶ → 確認
          │            │                         →「これで はじめる」→ 発表画面（セリフだけ大きく）
          │            │                         →「こたえを みる」→ 答え合わせ（セリフ＋選んだ気持ち）
          │            │                         → つぎの もんだい／おわる
          │            └─ もんだいに こたえる
          │                 「どんな きもち？」＋気持ちカード（横並び 2〜4枚）
          │                 → タップで全画面表示 → タップでカード一覧に戻る
          └─ せってい ── きもち／セリフ／ばめん／JSON かきだす・よみこむ
```

- **出題者の気持ちの確認**: セリフと気持ちを選ぶ間は**ミラーを切る**運用。発表画面になってから映す。
  発表画面には気持ちを出さない
- **場面モードの答え方**: 回答者は自分の iPad の**共通の気持ちカード**で答える。
  場面データに選択肢・正解・解説は持たない
- **場面＝だれかがセリフを言っている場面。** 同じセリフを違う気持ちで言う場面を2枚ずつ組にする
  （おはよう／ありがとう／いいよ／ごめんなさい）

## 4. データ

| データ | 中身 | 保存先 |
|---|---|---|
| 気持ち | 2〜4個。名前・アイコン画像・表示順。初期は うれしい・かなしい・おこっている・こわい（要件定義の「こまっている」を変更） | 端末のブラウザ |
| セリフ | 初期10個。追加・編集・削除・並べ替え | 端末のブラウザ |
| 場面 | 画像＋タイトル＋場面の説明＋セリフ | デフォルトはアプリに同梱。先生が追加した分は、その端末のブラウザ（IndexedDB）に個別に保存 |

- **生徒の iPad の設定をそろえる方法**: 先生の端末で設定を JSON に書き出す → AirDrop やドライブで配る → 生徒の端末で読み込む。
  書き出すのは気持ちとセリフだけ。画像は含めない
- 追加した画像を消さないため、先生の端末はホーム画面に追加して使う（Safari のデータ消去の対象外にするため。実機で要確認）

## 5. 画面の基本

大きなボタン・大きなカード・少ない選択肢。文字はひらがな（わかちがき）＋補助アイコン。
